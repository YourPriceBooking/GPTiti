# Оновлення токена (Refresh Token)

## Запит

- **URL:** `https://ypbooking.chost.com.ua/gpt-titi/api/users/refresh`
- **Метод:** `POST`
- **Тіло запиту:** не потрібне

---

## Успішна відповідь

```json
{
  "accessToken": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
}
```

---

## Помилки

**Статус `403`** повертається у наступних випадках:

- Переданий невірний токен
- Юзера не знайдено
- Юзер має статус **не активний**
- Токен не пошкоджений (не відповідає очікуваному формату)

```json
{ "error": "Invalid refresh token" }
```

---

## Термін дії

Рефреш токен живе **30 днів**.
